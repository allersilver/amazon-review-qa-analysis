# Amazon Review QA Analysis
## 분석 전에 데이터 신뢰성부터 검증했다

---

## 프로젝트 개요

Amazon 상품 리뷰 데이터를 단순 EDA가 아닌  
**데이터 품질 관리(QA) 관점**에서 분석한 프로젝트.

수집된 데이터가 분석과 서비스에 바로 사용 가능한지 먼저 검증하고,  
**품질 기준을 직접 설계하여 저품질 데이터를 정량적으로 탐지**했다.

분석 품질이 서비스 품질로 이어진다는 전제 아래,  
데이터를 신뢰하기 전에 데이터를 검증하는 과정 전체를 수행했다.

---

## 핵심 발견

- 전체 1,212건 중 **442건(36.5%)** 분석·서비스 활용 부적합 저품질 데이터 탐지
- **HomeImprovement(50%)**, OfficeProducts(45.2%) 카테고리에서 저품질 비율 높음
- 저품질 유형 3가지 분류 및 카테고리별 개선 기준 도출

| 저품질 유형 | 건수 | 기준 |
|------------|------|------|
| 저품질_길이 | 237건 | 텍스트 Q1(492자) 이하 |
| 저품질_URL | 137건 | https:// 포함 |
| 저품질_복합 | 68건 | 길이 짧고 URL 포함 |

---

## QA 기준 설계 과정

단순히 결측치·중복을 제거하는 전처리가 아닌,  
**"어떤 데이터가 신뢰할 수 없는가"를 기준부터 직접 정의**했다.

**형식 오류 탐지** (01_data_cleaning)
- 가격·할인율 특수문자(₹, %, 콤마) → 수집 파이프라인 구조 문제로 판단
- rating 이상값("|" 입력) 1건, 중복 리뷰 253건(17.3%) 제거
- 원본 1,465건 → 정제 후 1,212건

**리뷰 텍스트 품질 기준 설계** (04_review_quality)
- 기준 1: 텍스트 길이 → Q1(492자) 이하는 정보량 부족으로 저품질 분류
- 기준 2: URL 포함 여부 → 광고성·외부 링크 의존 리뷰로 저품질 분류
- 두 기준 조합으로 3가지 저품질 유형 정의

## Synthetic Data 생성 배경

실제 구매·이벤트 로그가 없어 사용자 행동 기반 분석이 불가능했다.  
이를 해결하기 위해 **QA로 도출한 품질 점수를 기반으로 사용자 9,050명과 이벤트 로그를 직접 설계·생성**했다.  
(상세 설계 과정: `02_synthetic_data.ipynb`)

이 합성 데이터는 이후 [user-engagement-product-analytics](https://github.com/allersilver/user-engagement-product-analytics) 프로젝트의 기반 데이터로 활용됐다.

---

## 가격·할인율 분석 인사이트 (03_price_analysis)

- 할인율 81~100% 구간 평균 평점 **3.98으로 가장 낮음** → 과도한 할인이 데이터 신뢰도 하락으로 이어짐
- 10K+ 고가 상품 평균 평점 **4.20으로 가장 높음** → 가격 구간이 품질 필터링 기준으로 활용 가능
- 평점의 61.5%가 4.0~4.5에 집중 → 평점 단독 지표 신뢰도 제한적, 다중 기준 필요
